# 100 Years Olympic Data Analysis Dashboard

An interactive Microsoft Excel dashboard exploring Olympic history through athlete participation, medal distribution, country performance, sports, and athlete-level trends.

##  Project Overview

The **Olympic Data Analysis Dashboard** transforms historical Olympic data into interactive visual reports. It explores participation patterns, medal distribution, and sporting performance across countries, sports, and Olympic years.

The project demonstrates practical data cleaning, transformation, analysis, and dashboard development using Microsoft Excel, Power Query, and Pivot Tables.

##  Key Features

- Interactive Excel dashboard with slicers and filters
- Olympic participation and medal summary metrics

##  Tools & Technologies

- **Microsoft Excel:** Dashboard development and data analysis
- **Power Query:** Data cleaning and transformation
- **Pivot Tables:** Data summarization and aggregation
- **Pivot Charts:** Visual comparison of Olympic statistics
- **Excel Slicers and Filters:** Interactive data exploration

##  Project Workflow

1. **Data Preparation:** Inspected the Olympic dataset and identified relevant fields.
2. **Data Transformation:** Used Power Query to prepare and structure data for analysis.
3. **Data Aggregation:** Created Pivot Tables to summarize participation and medal counts.
4. **Data Visualization:** Developed charts to analyze country performance, athlete achievements, sports, and participation patterns.
5. **Dashboard Development:** Organized visualizations into an interactive dashboard with relevant filters.
6. **Comparative Analysis:** Explored historical patterns and differences across countries, sports, ages, and genders.

##  Analytical Areas

The dashboard explores the following areas:

- Athlete participation and gender distribution
- Gold, silver, and bronze medal distribution
- Country-wise Olympic performance
- Top medal-winning athletes
- Popular sports and participation patterns
- Medal counts across athlete ages
- Country performance across Olympic years and seasons
- Height and weight comparisons with medal outcomes

##  How to Use

1. Download the Excel workbook from this repository.
2. Open the workbook in Microsoft Excel.
3. Navigate through the worksheet tabs to explore the dashboard and individual analyses.
4. Use the available slicers and filters to compare different categories.
5. Explore the charts and Pivot Tables to understand the data.
